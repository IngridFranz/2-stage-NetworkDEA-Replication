# Metadata files

- `variable_dictionary.csv` defines the machine-readable input fields.
- `data_construction_protocol.csv` records the source, vintage, reference
  period, unit, transformation, and imputation documentation available from
  Supplementary Tables 1 and 2 and their footnotes.
- `imputation_log.csv` records which country-variable cells were mean-imputed,
  without redistributing the imputed numerical values.
- `output_map.csv` links major manuscript and supplementary reporting elements
  to the files generated by `run_all.R`.

The supplement does not provide a unique database series code or a separate
reference year for every indicator. These fields have therefore not been
invented. If exact OECD, Eurostat, European Commission, or WHO series codes are
available from the original data extraction, add them before release.
